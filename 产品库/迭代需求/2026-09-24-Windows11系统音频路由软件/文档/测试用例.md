# 测试用例（初版，方案确认后形成）

同一套 TC-xxx 贯穿实现与验证；来源标注 PRD/原型/目标。技术设计与代码差异明确后再增量补充接口/集成/性能测试点。

| 编号 | 优先级 | Given | When | Then | 来源 |
|---|---|---|---|---|---|
| TC-001 | P0 | Win11 连麦中，网易云播放、抖音播放，聊天软件输入设备=AudioRouter 虚拟麦 | 仅勾选网易云共享 | 好友听到人声+网易云，听不到抖音；本地听感不变；说话不受影响 | PRD AC-01 |
| TC-002 | P0 | 网易云与抖音均已共享 | 仅拖低抖音音量滑杆至0 | 好友端抖音声消失，网易云与人声不变；本地听感不变 | PRD AC-02 |
| TC-003 | P0 | 任意共享进行中 | 点击总开关（文案切为"关闭共享"） | 好友端音乐消失、人声正常；本地播放不受影响 | PRD AC-03 |
| TC-004 | P1 | 全新安装后首次使用 | 按三步引导操作 | 首次配置≤5分钟达到共享效果（目标值） | PRD AC-04 |
| TC-005 | P1 | 共享持续开启 | 连续使用≥1小时 | 无回声/啸叫、无爆音、无内存持续增长、无可感知额外延迟 | PRD AC-05 |
| TC-006 | P1 | 虚拟声卡已装且正常 | 启动软件 | 显示"虚拟麦就绪"，无需手动配置 | PRD AC-06 |
| TC-007 | P2 | 网易云共享中 | 关闭网易云进程 | 已选栏移除该行且不弹窗；30秒内重开恢复原音量 | PRD AC-07 |
| TC-008 | P1 | 存在多个物理麦克风 | 底部下拉切换麦克风 | 人声来源实时切换、共享不断流 | PRD AC-08 |
| TC-009 | P1 | 无任何应用被勾选 | 查看已共享栏位 | 显示空态"勾选上方应用开始共享" | PRD 功能表 |

| TC-012 | P1 | 真实麦克风拔出/被占用 | 共享进行中 | 横幅提示"麦克风不可用"，音乐共享继续 | PRD 异常场景 |
| TC-013 | P2 | 输出设备切换（插拔耳机） | 共享进行中 | 重新绑定 loopback 端点，共享不断流；失败才提示 | PRD 异常场景 |
