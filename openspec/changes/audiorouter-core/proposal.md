# Proposal: AudioRouter 核心音频路由

## 背景
用户语音连麦时想把电脑上指定应用（网易云、抖音等）的声音连同人声一起共享给好友；现有工具（VB-Cable+Voicemeeter 手动配置）太复杂。目标/PRD 已确认（见 产品库/迭代需求/2026-09-24-Windows11系统音频路由软件/文档/）。

## 目标
- 按应用粒度选取一个或多个音频源，与物理麦克风人声混合写入虚拟麦克风
- 每源独立共享音量；本地播放不受影响；总开关一键启停
- Win11 兼容，首次配置 ≤5 分钟（三步引导）

## 范围
- 做：Tauri 2 桌面应用（Vue3 前端 + Rust 音频核心）、WASAPI Process Loopback 捕获、混音引擎、VB-CABLE 检测/引导安装、托盘常驻、配置持久化
- 不做：变声/混响/EQ、录音、macOS/Linux/Win10-、商业化分发（继承目标§5）

## 验收口径
PRD AC-01 ~ AC-08；测试用例 TC-001 ~ TC-017。
